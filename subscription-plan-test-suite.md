# Subscription Plan QC – Pricing Calculation Test Suite

## Scope & Traceability
| Requirement ID | Description |
| --- | --- |
| PC-R1 | Pricing Calculation screen header, layout, and navigation differ for New vs Edit flows (desktop/tablet/mobile behaviors). |
| PC-R2 | Plan Details grid enforces tier allocation, minimum therapist seats (>= active therapists), tooltips, no unit price column for therapist tiers. |
| PC-R3 | Non-therapist seats cannot exceed therapist seats; min equals current active non-therapists; tooltips display correctly. |
| PC-R4 | RCM add-on units mirror therapist seats when selected; checkbox behavior honors visibility rules. |
| PC-R5 | Checkbox defaults (Therapist locked on, other items reflect prior plan or unchecked for new clinics). |
| PC-R6 | Promotion code VR1–VR5, reapplication rules, and success messaging. |
| PC-R7 | Payment method presence required before Pay Now / Save Plan; Add/Change button links. |
| PC-R8 | Monetary calculations for Monthly/Annual charges, taxes, discounts (1-month, promo), previous plan proration, and non-negative total enforcement. |
| PC-R9 | Pay Now flow for first-time subscription: validation, CardConnect charge, success/failure routing, notifications. |
| PC-R10 | Save Plan upgrade path triggers immediate payment, terminates current plan/upcoming plan, and logs events. |
| PC-R11 | Save Plan downgrade path schedules upcoming plan, validates change detection, handles zero-dollar card verification, success emails, and restrictions. |
